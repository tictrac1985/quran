## المميزات

- **مصحف كامل** بخطوط طبعة 1441هـ (حزمة QCF4) وتخطيط الصفحات الحقيقي — كل صفحة تُرسم بخطها الخاص كما في المصحف المطبوع
- **تفسير وأسباب نزول** بالنقر على أي كلمة أو آية، مع تنقّل بين الآيات
- **بحث** في نص القرآن يظلّل الآية مكانها داخل الصفحة عند فتحها
- **رحلتي**: أوراد قراءة وحفظ ومراجعة بنظام تكرار متباعد (SRS)، شجرة حفظ السور، إحصاءات وسلسلة أيام
- **استئناف تلقائي** من آخر نقطة وصلت إليها
- **نسخ احتياطي** بملف واحد: تصدير بحوار «حفظ باسم»، أو حفظ مباشر في مجلد مزامنة OneDrive / Google Drive للاستعادة على جهاز آخر
- يعمل **بلا اتصال** بالكامل بعد البناء — كل الأصول محلية

## البناء من المصدر

المتطلبات: Node.js 18+ ،Rust (لتطبيق سطح المكتب) ،Python 3 مع Pillow (لتوليد الأيقونة).

```bash
npm install                        # اعتماديات الواجهة
python tools/fetch_qcf4.py         # تنزيل حزمة المصحف إلى src-tauri/assets (مرة واحدة)
python tools/make_icon.py          # توليد icon-src.png
npx tauri icon src-tauri/icons/icon-src.png   # اشتقاق كل مقاسات الأيقونات
```

### التشغيل في المتصفح (تطوير)

```bash
npm run dev
```

### بناء تطبيق سطح المكتب

```bash
npm run tauri build
```

ينتج مثبّت NSIS وملفاً تنفيذياً في `src-tauri/target/release`. النسخة المحمولة
تعمل بوضع `quran-app.exe` ومجلد `assets` جنباً إلى جنب.

## بنية المشروع

| المسار | الوصف |
|---|---|
| `src/` | واجهة React + TypeScript (القارئ، الفهرس، البحث، التفسير، الورود) |
| `src-tauri/` | غلاف Tauri/Rust: بروتوكول `mushaf://` للأصول، أوامر النسخ السحابي |
| `tools/` | سكربتات بايثون لجلب الأصول وبناء الفهارس والتفاسير |
| `docs/` | مصادر الأصول ورخصها وقرارات البنية ولقطات الواجهة |
